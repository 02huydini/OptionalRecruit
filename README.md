# A plugin for players to be picky.

### Core Problem
Random recruitment.

### What does this do?
Selective recruitment.

### Plugin requirement
Only Host need this plugin.

### How do I use it?
With OR: There's a menu in trader UI let you select a player.
Without OR: Chat out "Recruit [ID]" to select a player. This have 10 seconds cooldown apply for everyone

### Installation

5. Manage > Browse local file
6. Locate ..\BepInEx\plugins\ (You should know this if you have KrokMP, remember it as your default plugin folder)
